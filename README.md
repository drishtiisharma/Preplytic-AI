# Preplytic-AI 
### 🚧 Under Progress 🚧

Preplytic AI is a full-stack, AI-powered job readiness and application assistance platform designed to help candidates understand how well they match a specific job and prepare effectively for it.

### Things You Should be Able to do:
- Creating and Updating Personal Profile
- Saving job profiles through URL or JDs
- Choose between two main workflows:
  * Quick Apply
  * Interview Preparation
 
### What are These Workflows?
 
**<ins>Quick Apply</ins>** analyzes the user's resume against the selected job profile, provides job - match and ATS insights, identifies skill gaps, helps optimize the resume and help generate personal cold mail for HRs or Referral messages.

**<ins>Interview Preparation</ins>** allows the user to configure an AI-mock interview based on the selected job and their resume, evaluating their performance, generating an overall job - readiness report, and recieve a personalized interview preparation roadmap.

### What Will I be Using?
The platform will be built using Next.js, TypeScript, Tailwind CSS, shadcn/ui, FastAPI, SQLAlchemy, PostgreSQL/Supabase, LangChain, and LLM APIs, following a modular-monolith architecture with a feature-based frontend and layered backend.
